## 0. 한 문장 정의

헤르메스 디자인 시스템은 **차가운 AI 기능을 따뜻한 인간 맥락 안에 안전하게 담는 OS-native visual language**다.

AI는 과시적인 생성 엔진, 감시 대시보드, 로봇 캐릭터가 아니다. Hermes에서는 AI를 사용자의 삶·업무·이동 맥락 사이를 부드럽게 완충하고 초점화하는 조용한 지능 레이어로 표현한다.

## 1. Chris Archive에서 무엇을 얻었나

Chris Archive 60개 reference에서 얻은 것은 특정 이미지의 표면 스타일이 아니라, Chris가 반복적으로 끌린 **판단 신호의 구조**다.

### 얻은 것
- 부드러운 컨테이너: squircle, capsule, orb, protected void
- 조용한 지능: ambient dashboard, context card, low-noise metric
- warm-cool balance: cobalt/cyan system intelligence + coral/orange/yellow human warmth
- 촉각적 디지털 물성: frosted glass, gel, cushion, lens, halftone grain
- orbit/dot rhythm: AI processing과 relation을 점·선·궤도·호흡으로 표현
- editorial archive language: 큰 여백, micro metadata, specimen card, version marker
- human-system contrast: 사람의 맥락과 추상 시스템 오브젝트를 한 화면에 배치

### 버린 것
- 제3자 브랜드명, 캠페인 슬로건, 아티스트/프로젝트명
- 기존 로고, 워드마크, 앱 아이콘 실루엣
- 특정 포스터의 exact layout
- 이미지 안의 literal UI copy
- 특정 브랜드를 떠올리게 하는 색 비율/문구/구도

### 변환 방식
Reference → Evidence → Repeated Pattern → Compressed Cluster → Token / Component / Prompt Package / Critique Checklist

## 2. 압축된 핵심 클러스터 6개

### 01. Soft Ambient Intelligence
AI는 말하는 캐릭터가 아니라 사람의 업무·감정·이동 맥락을 조용히 완충하는 OS 레이어다.

- signals: ambient dashboard, context card, low-noise metric, gentle suggestion
- asset use: AI status card, companion widget, OBD signal card, calm productivity surface
- caution: 사람을 평가하거나 감시하는 인상을 만들지 않는다.

### 02. Protected Luminous Container
soft squircle, capsule, orb, luminous rim이 privacy와 focus를 담는 안전한 컨테이너가 된다.

- signals: protected void, glowing boundary, frosted shell, inner depth
- asset use: Hermes icon, secure context window, loading/listening state, protected memory object
- caution: generic gradient blob처럼 보이지 않게 경계와 내부 의미를 분명히 한다.

### 03. Warm-Cool Human System Balance
blue/cyan의 시스템 지성과 coral/orange/yellow의 인간적 온도를 한 화면에서 균형화한다.

- signals: charcoal/soft-white base, cobalt/cyan intelligence, coral warmth, muted yellow agency
- asset use: color tokens, action signal, state indicator, premium dark/light mode palette
- caution: neon rainbow나 startup AI glow로 흐르지 않는다.

### 04. Tactile Optical Material
AI를 추상적인 빛이 아니라 손에 닿을 듯한 glass/gel/cushion/lens 물성으로 만든다.

- signals: frosted glass, soft gel, halftone grain, optical blur, membrane surface
- asset use: hero object, package surface, soft-3D brand object, dashboard card material
- caution: hard chrome, sharp glass, 과한 liquid metal은 보조 motif로만 제한한다.

### 05. Orbital Signal Rhythm
AI processing과 관계성을 dot, orbit, pulse, circular node의 리듬으로 표현한다.

- signals: dot matrix, orbit line, radial node, breathing glow, signal density
- asset use: voice state, confidence indicator, progress, agent loop, context graph motion
- caution: processing을 fake precision이나 distraction으로 만들지 않는다.

### 06. Quiet Editorial Archive
큰 여백, micro metadata, archive label, two-panel contrast로 디자인 시스템을 연구 기록물처럼 보이게 한다.

- signals: large negative space, micro label, specimen card, vinyl/archive object, human-system contrast
- asset use: design-system chapter, archive cover, brand guideline spread, package label system
- caution: 제3자 포스터 문구·레이아웃·숫자 시스템을 그대로 복제하지 않는다.

## 5. 평가 체크리스트

### DNA Match
- Soft Ambient Intelligence가 느껴지는가?
- Protected Luminous Container가 보이는가?
- Warm-Cool Human System Balance가 유지되는가?
- Tactile Optical Material이 과하지 않게 존재하는가?
- Orbital Signal Rhythm이 상태/관계를 설명하는가?
- Quiet Editorial Archive 감각이 있는가?

### Brand Safety
- 제3자 브랜드, 문구, 로고, 레이아웃을 연상시키지 않는가?
- reference를 복제한 느낌이 아니라 원리만 추출했는가?
- AI cliché, startup neon, surveillance metaphor를 피했는가?

### UX Fit
- 사람의 agency가 보이는가?
- pause/correct/hide/source-visible 같은 통제 가능성이 느껴지는가?
- One UI / Hermes / OBD 맥락에서 실제 제품 언어로 확장 가능한가?

## 6. Do / Don't

### Do
- AI를 조용한 OS layer로 표현한다.
- warm/cool balance를 유지한다.
- soft squircle, capsule, orb, frosted card를 반복 가능한 토큰으로 쓴다.
- privacy, agency, correction, pause affordance를 포함한다.
- dot/rhythm/progress로 AI processing을 차분하게 표현한다.
- archive object와 metadata label을 brand/documentation layer에 활용한다.

### Don't
- generic AI startup neon/glassmorphism으로 가지 않는다.
- robot, brain, magic sparkle, surveillance metaphor를 쓰지 않는다.
- 감정/건강/행동 데이터를 단정하거나 평가하지 않는다.
- KPI dashboard처럼 사용자를 압박하지 않는다.
- 제3자 브랜드/문구/로고/레이아웃을 복제하지 않는다.
- liquid metal/chrome/rainbow를 핵심 문법으로 과용하지 않는다.
