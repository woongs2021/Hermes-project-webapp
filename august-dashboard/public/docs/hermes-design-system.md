## 1. 한 문장 정의

**헤르메스는 사람의 맥락을 보호하는 조용한 지능입니다.**

차가운 AI 기능을 따뜻한 인간 리듬 안에 담아, 사용자가 더 안전하게 판단하고 멈추고 수정할 수 있게 돕는다.

## 2. Chris Archive에서 무엇을 얻었나

Chris Archive 60개는 스타일 모음이 아니라 Chris가 AI 시대의 UX에서 중요하게 느끼는 감각의 반복이다.

### 얻은 것
- 보호되는 맥락: privacy, protected void, soft container, user agency
- 따뜻한 시스템 지성: cobalt/cyan intelligence + coral/yellow warmth
- 조용한 신호 리듬: orbit, dot matrix, soft pulse, low-noise progress
- 촉각적 디지털 물성: frosted glass, gel, cushion, lens, halftone grain
- editorial evidence: 큰 여백, micro metadata, specimen card, archive label
- soft presence object: icon보다 넓은 의미의 조용한 존재감

### 복제하지 않는 것
- 제3자 브랜드명, 슬로건, 아티스트/프로젝트명
- 기존 로고, 워드마크, 앱 아이콘 실루엣
- 특정 포스터의 exact layout
- 이미지 안의 literal UI copy
- 특정 브랜드를 떠올리게 하는 색 비율/문구/구도

## 3. Core DNA 3개

### 01. Protected Human Context
Hermes는 사용자를 분석하거나 과시하지 않고, 사용자의 맥락을 보호하는 조용한 AI 레이어다.

- signals: privacy, protected void, soft container, calm AI presence, user agency
- asset use: Hermes Presence Mark, secure context window, memory object, AI mode surface
- caution: surveillance, emotional scoring, judgmental UI를 피한다.

### 02. Warm-Cool Intelligence
차가운 시스템 지성과 따뜻한 인간 온도가 한 화면 안에서 균형을 이룬다.

- signals: cobalt intelligence, cyan sensing, coral warmth, muted yellow agency, charcoal base
- asset use: core palette, state indicator, action signal, premium OS mode
- caution: neon rainbow나 generic AI startup glow로 흐르지 않는다.

### 03. Quiet Signal Rhythm
AI의 작동은 번쩍이는 효과가 아니라 점, 궤도, 숨쉬는 경계, 낮은 밀도의 리듬으로 표현된다.

- signals: orbit, dot matrix, soft pulse, low-noise progress, pause/correct/hide
- asset use: agent loop, voice state, processing motion, confidence indicator
- caution: fake precision, excessive motion, sci-fi HUD를 피한다.

## 4. Expression Layer 3개

### 04. Tactile Optical Material
Glass, gel, cushion, lens는 AI를 차가운 기술이 아니라 손에 닿는 듯한 물성으로 낮춘다.

### 05. Editorial Evidence System
Archive label, micro metadata, 큰 여백은 Chris의 디자인 판단을 신뢰 가능한 연구 기록물로 만든다.

### 06. Soft Object / Presence Mark
아이콘보다 넓은 개념의 presence mark로 Hermes의 조용한 존재감을 먼저 고정한다.

## 5. First Asset Direction

첫 생성은 **Hermes Presence Mark**부터 시작한다.

이유:
- 가장 작고 강하게 브랜드 DNA를 검증할 수 있다.
- Protected Human Context, Warm-Cool Intelligence, Quiet Signal Rhythm, Soft Object가 한 번에 드러난다.
- 성공하면 archive cover, AI dashboard card, OBD signal, package seal로 확장하기 쉽다.

## 6. 브랜드 에셋 생성용 프롬프트 패키지

### 공통 prefix
Original Hermes design-system asset based on repeated visual principles from an internal design archive, not copying any existing brand, text, logo, artwork, poster layout, app icon, or campaign.

### 공통 negative prompt
No readable third-party text, no brand names, no logos, no exact reference layout, no robot, no brain symbol, no magic sparkle, no generic AI startup neon gradient, no surveillance dashboard, no fake UI copy, no copyrighted character, no known package label imitation.

### Package 01 — Hermes Presence Mark
Prompt:
Original Hermes presence mark, protected luminous soft orb or open squircle container, soft inner void, tactile gel-glass rim, warm-cool cobalt and coral signal balance, premium OS-native calm intelligence, subtle optical depth, high-end minimal object, no text.

Guardrail:
- 기존 앱 아이콘이나 로고 구조를 닮으면 폐기한다.

### Package 02 — Ambient AI Context Card
Prompt:
Original calm AI context card for human context intelligence, frosted bento panels, dot-matrix soft metrics, low-noise micro charts, coral action signal inside mist-gray and cobalt system palette, spacious One UI-like hierarchy, user agency controls visible, warm and trustworthy, no surveillance feeling, no KPI pressure.

Guardrail:
- dashboard가 아니라 사람의 맥락을 보호하는 context surface로 보여야 한다.

### Package 03 — OBD Context Signal Field
Prompt:
Original onboard AI context field visual, orbital signal rhythm around a protected driver context zone, subtle cyan sensing lines, warm yellow agency cue, low amplitude motion-ready composition, calm safety-first interface object, premium automotive OS mood, minimal information density, no distraction, no racing metaphor.

Guardrail:
- 빠른 HUD, 과한 경고, 운전 중 시선 부담 요소를 피한다.

### Package 04 — Hermes Archive Cover
Prompt:
Original editorial archive cover for Hermes Design DNA, large negative space, tactile archive label, micro metadata, soft glass specimen object, charcoal and warm white base, quiet premium research document mood, subtle paper grain, no copied poster layout, no readable third-party slogans.

Guardrail:
- 특정 포스터/매거진/음악 레이블 그래픽처럼 보이면 폐기한다.

### Package 05 — Brand Package Label System
Prompt:
Original brand and package label system derived from Hermes Design DNA, rounded label geometry, protected central void, tactile paper-grain and soft glass accent, warm-cool signal stripe, micro version markers, premium shelf presence, adaptable to bottle, box, pouch, can, and label systems without copying any existing brand.

Guardrail:
- 기존 브랜드 로고/색 비율/라벨 구조를 직접 닮으면 폐기한다.

## 7. What Hermes should never become

- generic AI startup neon / sparkle / blob aesthetic
- robot, brain, mascot, surveillance dashboard metaphor
- 감정·건강·업무 데이터를 단정하거나 평가하는 tone
- KPI 압박감이 강한 enterprise dashboard
- 제3자 브랜드명, 문구, 로고, 포스터 레이아웃 복제
- 과한 chrome, liquid metal, rainbow gradient를 핵심 문법으로 쓰는 것
