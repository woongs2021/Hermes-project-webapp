## 0. 한 문장 정의

헤르메스 디자인 시스템은 **차가운 AI 기능을 따뜻한 인간 맥락 안에 안전하게 담는 OS-native visual language**다.  
AI를 과시적인 생성 엔진이나 감시 대시보드로 보이게 하지 않고, 사용자의 삶·업무·이동 맥락 사이를 부드럽게 완충하고 초점화하는 조용한 지능 레이어로 표현한다.

## 1. 디자인 원칙

### 1. Quiet Intelligence
- AI는 전면에서 “말하는 캐릭터”가 아니라, 배경에서 상황을 정리하는 조용한 레이어다.
- 상태, 제안, 자동화는 작은 카드·점·캡슐·라벨로 표현한다.
- 화려한 AI sparkle, 로봇, 두뇌, 마법 같은 은유는 쓰지 않는다.

### 2. Human Warmth inside System Clarity
- 시스템은 명확해야 하지만 차갑게 보이면 안 된다.
- blue/cyan은 system intelligence, orange/coral/yellow는 human warmth와 action signal로 쓴다.
- warm accent는 장식이 아니라 피드백, 전환, 주의, 선택 가능성에만 사용한다.

### 3. Protected Context
- 사용자의 감정, 건강, 업무, 이동 맥락은 보호된 컨테이너 안에 담긴다.
- void, rim, soft boundary, frosted container는 privacy와 focus를 상징한다.
- 개인 상태는 단정하지 않고, 수정·숨김·삭제·일시정지 가능성을 함께 보여준다.

### 4. Tactile Digital Material
- AI는 빛만 있는 무형 물체가 아니라 손에 닿을 듯한 부드러운 material로 표현한다.
- frosted glass, soft gel, cushion, membrane, capsule, optical lens, halftone grain을 우선한다.
- hard chrome, sharp glass, excessive neon glow는 보조 레이어로만 제한한다.

### 5. Archive as Living System
- Hermes의 기억과 디자인 DNA는 데이터베이스가 아니라 살아있는 archive object처럼 다룬다.
- version marker, metadata label, specimen card, vinyl/label metaphor를 제한적으로 사용한다.
- 기록은 결과물이 아니라 다음 에셋 생성을 위한 source material이다.

## 2. 핵심 DNA 클러스터

### A. Soft Ambient Intelligence
반복 신호: ambient AI dashboard, personal context card, emotional/work state, low-noise metrics.  
사용처: One UI AI 요약, 업무/건강/이동 상태 카드, Hermes agent status.  
주의: 사람을 평가하거나 감시하는 인상을 만들지 않는다.

### B. Protected Luminous Container
반복 신호: squircle, capsule, orb, chromatic rim, protected void, glowing edge.  
사용처: app icon, AI mode indicator, secure context window, listening/thinking state.  
주의: generic gradient blob처럼 보이지 않게 경계와 내부 의미를 분명히 한다.

### C. Warm-Cool Equilibrium
반복 신호: cobalt/cyan + coral/orange/yellow, black/white/gray base, muted violet.  
사용처: 상태 색, action cue, OS mode, dashboard hierarchy.  
주의: neon rainbow나 startup AI glow로 흐르지 않는다.

### D. Orb / Orbit / Feedback Field
반복 신호: orbit line, sphere, eclipse, circular navigation, radial nodes, contact point.  
사용처: context graph, agent loop, feedback, voice/media state, OBD signal field.  
주의: cosmic fantasy가 아니라 feedback/system relation으로 읽히게 한다.

### E. Modular Soft System
반복 신호: rounded bento, glass card, metric tile, dot-matrix number, progress capsule.  
사용처: dashboard, design token board, agent capability grid, workflow cards.  
주의: enterprise SaaS처럼 딱딱하거나 KPI 압박감이 강해지지 않게 한다.

### F. Human-Scale Interaction
반복 신호: hand, thumb reach, phone, face/profile, cockpit, health/work context.  
사용처: mobile AI companion, OBD assistant, wellness dashboard, context overlay.  
주의: 감정/건강/행동 데이터는 consent, correction, hide/delete affordance를 포함한다.

### G. Quiet Editorial System
반복 신호: monochrome poster, large negative space, micro metadata, oversized grotesk type.  
사용처: design-system chapter opener, archive cover, principle spread, campaign layer.  
주의: 제3자 포스터 문구·레이아웃·숫자 시스템을 그대로 복제하지 않는다.

### H. Analog Archive Object
반복 신호: vinyl label, track/side marker, grain, printed surface, physical media.  
사용처: memory archive, versioned design tokens, package/sticker/label system.  
주의: 물리 매체 은유는 archive와 brand documentation에 집중하고 UI 전반에 남발하지 않는다.

### I. Signal / Dot / Rhythm
반복 신호: dot matrix, progress dots, stripe density, scanline, LED bead, reaction blocks.  
사용처: AI processing, loading, voice state, confidence indicator, low-noise chart.  
주의: 처리 상태를 fake precision으로 보이게 하지 않는다.

### J. Human-System Editorial Contrast
반복 신호: cinematic human image + abstract system object, two-panel poster, white-space contrast.  
사용처: strategy deck, onboarding, brand narrative, AI/OBD transition story.  
주의: human image가 trapped/surveilled처럼 보이지 않게 agency framing을 둔다.

## 3. 컬러 시스템

### Base
- Soft White: quiet canvas, documentation, modal surfaces
- Mist Gray: background depth, card separation
- Warm Taupe: human warmth, non-clinical neutrality
- Charcoal / Near Black: premium void, archive frame, focus field
- Deep Navy: system intelligence, dark mode depth

### Accent
- Cobalt Blue: intelligence, focus, system depth
- Cyan / Teal: sensing, clarity, live signal
- Coral / Red Orange: human signal, urgency, energy, emotional warmth
- Muted Yellow / Gold: pause, agency, attention, optimism
- Violet / Magenta: ambiguity, emotional depth, transition
- Lime Green: technology signal, but use sparingly because campaign/agency references can feel strong

### Color rule
한 화면에서는 **neutral base 80–90% + one warm/cool accent pair 10–20%**를 기본으로 한다. Accent는 예쁜 색이 아니라 상태와 행동의 의미를 가져야 한다.

## 4. Typography

### Recommended
- Neutral sans-serif for product UI
- Rounded grotesk for warm system headings
- Condensed or oversized grotesk only for editorial/campaign layer
- Thin metadata labels for archive/version information
- Dot-matrix numerals for soft KPI/status expression

### Rules
- UI 본문은 명확하고 낮은 압박감의 sans-serif를 사용한다.
- 감정/건강/행동 상태 라벨은 짧고 조심스럽게 쓴다.
- 큰 타이포는 chapter opener나 poster layer에만 사용한다.
- 제3자 포스터의 문구, 숫자, 아티스트명, 프로젝트명은 복제하지 않는다.

## 5. Component Grammar

### Core components
- Soft glass card
- Frosted metric tile
- Dot-matrix number card
- Glass capsule progress bar
- Rounded bento container
- Context summary card
- AI status pill
- Floating companion card
- Circular navigation node
- Protected squircle icon
- Agent command token
- Metadata label / version marker
- Low-noise micro chart
- Warm signal button
- Pause / hold / user-control affordance

### Component rules
- Radius는 크게, shadow는 낮게, contrast는 안정적으로 둔다.
- 카드들은 “정보 덩어리”가 아니라 판단 가능한 context object여야 한다.
- progress와 metrics는 경쟁/압박보다 상황 이해를 돕는 tone으로 표현한다.
- AI가 무엇을 하고 있는지, 사용자가 어떻게 멈출 수 있는지 보여준다.

## 6. Layout System

### Repeating structures
- Central hero object + large negative space
- Rounded card / bento dashboard
- Floating context cards around human anchor
- Two-panel contrast: human context vs system object
- Circular/radial navigation
- Edge metadata and micro labels
- Summary → detail hierarchy
- Large object + tiny precision label

### Responsive principle
- Desktop: broad archive/dashboard view, 6-column scanning possible
- Tablet: 3-column browsing, popup should avoid clipped width
- Mobile: 2-column archive scan, popup behaves like a soft bottom sheet

## 7. Motion Language

### Allowed motion
- Soft pulse
- Breathing glow
- Orbiting
- Dot density shift
- Lens focusing
- Capsule sliding
- Gentle expansion/contraction
- Card floating/settling
- Cushion compression

### Motion rule
Motion은 “AI가 살아있다”가 아니라 “상태가 바뀌고 있다”를 알려야 한다. 빠른 shimmer, magical particle, flashy reveal은 피한다. OBD/운전 맥락에서는 amplitude와 frequency를 낮춘다.

## 8. Brand Safety

### Never copy
- Third-party brand names
- Artist/project names
- Campaign slogans
- Existing logos or wordmarks
- Exact poster layouts
- Exact icon silhouettes
- Literal UI copy from reference images

### Safe extraction
- 문구는 버리고 구조만 추출한다.
- 로고는 버리고 geometry relationship만 추출한다.
- 포스터는 버리고 object/void/metadata contrast만 추출한다.
- 컬러는 exact palette가 아니라 역할로 추출한다.
- 특정 사진 mood는 복제하지 않고 human context + system abstraction 원리로 변환한다.

## 9. Do / Don't

### Do
- AI를 조용한 OS layer로 표현한다.
- warm/cool balance를 유지한다.
- soft squircle, capsule, orb, frosted card를 반복 가능한 토큰으로 쓴다.
- privacy, agency, correction, pause affordance를 포함한다.
- dot/rhythm/progress로 AI processing을 차분하게 표현한다.
- archive object와 metadata label을 brand/documentation layer에 활용한다.
- 인간의 손, 시선, 이동, 업무 리듬을 존중하는 scale로 설계한다.

### Don't
- generic AI startup neon/glassmorphism으로 가지 않는다.
- robot, brain, magic sparkle, surveillance metaphor를 쓰지 않는다.
- 감정/건강/행동 데이터를 단정하거나 평가하지 않는다.
- KPI dashboard처럼 사용자를 압박하지 않는다.
- 제3자 브랜드/문구/로고/레이아웃을 복제하지 않는다.
- liquid metal/chrome/rainbow를 핵심 문법으로 과용하지 않는다.

## 10. Asset Generation Principles

### Prompt recipe
1. Start with: “Original Hermes design-system asset based on repeated visual principles, not copying any existing brand, text, logo, or layout.”
2. Add one structural cluster: soft container / bento dashboard / orbital field / archive object.
3. Add one material: frosted glass / gel membrane / cushion / optical lens / paper grain.
4. Add one color role: warm-cool signal balance / charcoal void / soft white canvas.
5. Add one UX meaning: protected context / user agency / calm processing / low-noise intelligence.
6. Forbid: readable third-party text, logos, exact poster layout, stock AI symbols, neon cyber glow.

### Quality checklist
- 차분한가?
- 고급스러운가?
- 인간적인 온도가 있는가?
- AI cliché를 피했는가?
- One UI / Hermes / OBD 맥락에 맞는가?
- 사용자의 agency와 privacy가 느껴지는가?
- 제3자 브랜드를 연상시키지 않는가?
- 반복 가능한 design-system token으로 환원 가능한가?
