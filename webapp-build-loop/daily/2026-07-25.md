## 구조 브리프

`VisualSourceStatusGate`는 `HomeVisualSetAdapter`가 파일을 읽기 전후에 source 상태를 판단하는 얇은 read-only gate 후보입니다.

- `/` 홈 canonical: `final/current-home-visual-set.json` + `canonical_status: final_current`만 허용.
- `/visuals` 기본 archive: `final_current`, `archived_final` 허용.
- 비공개/admin review: `pending_review`를 optional preview로 허용 가능.
- fallback: canonical 파일이 없거나 3장 검증 실패 시 최신 날짜별 final JSON 또는 items feed를 읽되, fallback 상태를 UI/로그에 명확히 표시.
- public field: `title`, `theme`, `metaphor`, polish된 `why`만.
- private/admin field: `model`, `source_path`, `asset_path`, `prompt_policy`, `private_prompt_path`, `source_status` 등은 접힌 메타데이터로 분리.

## 데이터 후보

`VisualSourceStatusGate` 필드 후보:

- `source_status`: `final_current | archived_final | pending_review | fallback | invalid`
- `allowed_routes`: `/`, `/visuals`, `/admin/review` 중 허용 목록
- `public_field_allowlist`
- `private_field_allowlist`
- `asset_health`: still/video 존재 여부
- `promotion_rule`: Chris 최종 저장 phrase 또는 end-of-day finalizer 이후만 current home 교체
- `rejection_reason`: pending, missing_asset, not_three_items, private_only 등
